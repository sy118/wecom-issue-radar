# Proposal

## Why

「高情商回复」目前无法按会话选择提示词：提示词库虽然可以建多条 `eq_reply` 提示词，但后端固定取第一条，所有群共用同一套角色口径。用户在不同群里角色不同（客户、供应商、内部同事），需要每个群单独选择提示词并补充本群角色说明。

同时，生成链路存在明显的等待问题：回复模型请求超时上限被压到 120 秒，带图片请求失败后会再完整重试一次纯文本，最坏要等约 240 秒；页面统一显示“AI 暂时不可用，已返回规则版通用措辞”，无法区分超时、图片不支持、返回不完整或未配置模型。

## What Changes

- **按会话绑定提示词**
  - 每个已添加会话可选择提示词库中的一条 `eq_reply` 提示词，并可选填写 ≤500 字的「本群角色补充」。
  - 绑定关系保存在回复运行时的会话清单中；切换群自动带出，其他群不受影响。
  - 未绑定或提示词被删除时回退到默认 `eq_reply` 提示词，不阻塞生成。
- **生成提速**
  - 带图请求最多 3 张图片并限制总字节；带图尝试 20～25 秒，失败后纯文本最多再 15～20 秒，单次生成总预算 ≤45 秒。
  - 仅在模型明确不支持图片/图片输入被拒绝时重试纯文本；超时、JSON 解析失败、空响应不再触发第二次长等待。
  - 上下文与多选消息默认上限收紧；页面提供「带图片理解」开关。
- **可解释的回退**
  - 生成结果返回耗时、尝试次数与回退原因；页面显示「AI 生成 · 8.4 秒」或「本地模板 · 1.2 秒」。
  - 按原因展示文案（未配置/超时/图片不支持/返回不完整/网络错误），不再统一说“AI 暂时不可用”。
  - 「规则版」统一改称「本地模板」。

## Capabilities

### Modified Capabilities

- `wecom-high-eq-reply`: 新增按会话提示词绑定；调整生成超时、图片数量与回退语义；新增耗时/回退原因展示。

## Impact

- **后端**：`worker/reply_runtime/store.py`、`runtime.py`（`prompt_id`/`prompt_note` 列、`chat.prompt.set`、recent/catalog 字段）；`worker/reply_assistant/{prompts,actions,model}.py`（按 ID 选提示词、角色补充、超时预算、错误分类、耗时/回退原因）；`worker/reply_assistant/images.py`（图片张数与总字节限制）。
- **前端**：`src/App.tsx`（传入 config）、`src/pages/wecom/HighEqReplyPage.tsx`、`highEqReply.logic.ts/css`、测试；新增提示词选择/角色补充、图片开关、耗时与原因展示。
- **测试**：Python 覆盖提示词绑定与解析、预算/重试、错误原因、图片限制；前端覆盖 payload、提示词选项、回退文案、耗时展示。
- **文档**：README / docs 同步“每群提示词”和“生成耗时/回退原因”。
