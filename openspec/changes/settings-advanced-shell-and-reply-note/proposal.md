# Proposal

## Why

「设置 → 常用与高级」里的高级模式目前无法正常保存：高级页自己的「保存设置」按钮被嵌入样式 `display:none` 隐藏，而常用页的保存按钮只提交常用页维护的草稿，导致高级页的修改没有保存入口。同时高级页嵌入后缺少独立标题栏与保存状态，tabs、卡片和字段间距不统一，在 1024 宽度下显得拥挤。

高情商回复在选中消息后只能依赖上下文和固定的「本群角色补充」，缺少一次性的补充说明（例如“这次先安抚，承诺周五前给方案”）。这类内容不应长期保存到群配置，但需要参与本次生成。

## What Changes

- **高级设置保存修复**
  - 高级模式提供始终可见的「保存设置」入口，并显示「有未保存修改 / 已保存」状态。
  - 切换「常用 / 高级」或离开页面前提示未保存修改。
  - 长表单提供吸底保存条，滚到底仍可保存。
- **高级页布局与样式统一**
  - 高级模式使用独立的紧凑工具栏，不再隐藏整行页头造成没有标题和保存按钮。
  - tabs、卡片、字段网格与页面间距统一；1024×700、深色模式不横向溢出、不重叠。
  - 低频配置备份与迁移单独成块，不与当前 tab 的主要设置混在一起。
- **高情商回复的本次补充要求**
  - 选中消息后（也可在手动输入模式）可填写最多 500 字的「本次补充要求」。
  - 内容只影响当次生成，不写入会话配置、不保存到群；切换会话清空，重新生成时保留。
  - 作为「本次回复补充要求」追加到模型提示词，三版草稿都遵循。

## Capabilities

### Modified Capabilities

- `desktop-ui-system`: 新增「常用与高级设置页」需求，约束高级模式的保存入口、未保存状态、嵌入布局与最小窗口可用性。
- `wecom-high-eq-reply`: 新增「本次生成补充要求」需求，约束临时输入、prompt 注入与不持久化。

## Impact

- **前端**：`src/pages/SettingsHome.tsx`、`src/pages/SettingsPage.tsx`、`src/nav.css`/`src/redesign.css`（高级壳层、保存状态、吸底操作、tabs/卡片）；`src/pages/wecom/HighEqReplyPage.tsx`、`highEqReply.logic.ts`、`highEqReply.css`、测试。
- **后端**：`worker/reply_assistant/actions.py`、`prompts.py`（接收并注入 `replyInstruction`）；无新增持久化字段，无配置 schema 变更。
- **测试**：高级设置保存/切换提示、样式回归；补充要求 payload、prompt 注入、切换清空、不持久化。
