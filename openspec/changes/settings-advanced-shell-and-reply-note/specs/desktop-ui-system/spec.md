# Spec Delta

## ADDED Requirements

### Requirement: 常用与高级设置页的保存与布局

系统 SHALL 在「设置 → 常用与高级」的高级模式提供始终可见的保存操作，并用「有未保存修改 / 已保存」状态反馈当前草稿；用户切换常用/高级或离开页面前，存在未保存修改时 MUST 先提示确认。高级页面 MUST 使用单一滚动容器和一致的 tabs、卡片、字段间距，在 1024×700 与深色模式下不得出现横向滚动、按钮被裁切或保存入口消失。

#### Scenario: 保存高级设置

- **WHEN** 用户在高级模式修改任意设置并点击「保存设置」
- **THEN** 修改通过现有配置保存链路写入本机配置，页面显示保存成功，按钮恢复为「已保存」

#### Scenario: 未保存状态

- **WHEN** 高级模式草稿与已保存配置不一致
- **THEN** 顶部显示「有未保存修改」，保存按钮可用；没有修改时按钮禁用并显示「已保存」

#### Scenario: 切换模式前提醒

- **WHEN** 高级模式存在未保存修改，用户点击「常用」或离开设置页
- **THEN** 页面提示是否放弃未保存修改，取消时停留在当前模式并保留草稿

#### Scenario: 最小窗口可用

- **WHEN** 窗口缩小到 1024×700
- **THEN** 高级页的保存按钮、tabs 与表单均可见可操作，内容不横向溢出

#### Scenario: 长表单滚动后仍可保存

- **WHEN** 用户在高级页滚动到长表单底部且存在未保存修改
- **THEN** 吸底保存操作可见，点击后保存当前草稿
